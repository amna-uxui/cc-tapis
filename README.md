# cc-tapis

DXD Workshop with parcstudio.

## What if people could interact with carpets digitally?

Mobile-first prototype in the look and feel of cc-tapis (Milano). One screen, no scroll: a carpet in the middle, and one interaction we design and refine.

## Run it

```bash
python3 tools/serve.py
```

Then open http://localhost:8000 (use the browser's phone view, or your phone on the same Wi-Fi).

## Files

- `index.html`: the single screen (logo, carpet with arrows, bottom controls)
- `css/tokens.css`: design language (colours, fonts, sizes, spacing)
- `css/main.css`: layout of the screen
- `images/`: carpet photos
